# Отчет по загрузке старого каталога в Supabase

Дата импорта: 2026-06-06

## Режим

Реальная запись в подтвержденный тестовый Supabase.

Боевой Supabase в рамках этого work plan не использовался.

## Выполненные команды

```text
npm.cmd run catalog:import:validate
npm.cmd run storage:ensure
npm.cmd run catalog:import:dry-run
npm.cmd exec tsx scripts/import-old-catalog.ts -- --write --confirm-write=OLD_CATALOG_IMPORT
npm.cmd run catalog:import:dry-run
npm.cmd run db:check
npm.cmd run catalog:import:check
```

## Результат записи

Команда записи завершилась успешно:

```text
Импорт старого каталога записан в Supabase.
Товары: создано 86, обновлено 0.
Вкусы: создано 108, обновлено 0.
Фото: подготовлено 82.
```

## Проверка после записи

`npm.cmd run catalog:import:check` показал:

- категорий: 7;
- товаров: 86;
- вкусов: 108;
- images с путями `old-catalog/`: 82;
- файлов в Storage `old-catalog/`: 82;
- публичных ссылок фото открывается: 82/82.

## Повторный dry-run

Повторный `npm.cmd run catalog:import:dry-run` после записи показал:

- категорий найдено: 7;
- images создать: 0;
- images обновить: 82;
- товары создать: 0;
- товары обновить: 86;
- товары-черновики среди импортируемых: 4;
- вкусы создать: 0;
- вкусы обновить: 108.

Это подтверждает, что повторный запуск не создает дубли всего каталога.

## Черновики

Товары, которые остались в статусе `draft` из-за отсутствующего основного фото:

- `горная 5л`;
- `К-13`;
- `родники 0,5л`;
- `южания 0.2 детский`.

## Не входило в работу

- загрузка в боевой Supabase;
- исправление отсутствующих фото у черновиков;
- удаление неиспользуемых фото;
- клиентский каталог на реальных данных;
- деплой.
