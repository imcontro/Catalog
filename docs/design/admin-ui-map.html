UX направление

Спокойная рабочая панель вместо витрины товаров

Админка должна объяснять следующий шаг: где добавить товар, где найти черновики, где скрытые позиции, где категории и где сортировка. Главный принцип черновика - не прятать действия в догадках и не заставлять помнить внутреннюю логику проекта.

Этот список можно править прямо на странице. После утверждения решения переносятся в design spec и отдельный work plan.

Навигация

  • Главная админки объясняет все разделы простыми словами.
  • Вкладки одинаковые на списках товаров, категорий и сортировки.
  • Кнопка выхода остается доступной, но не конкурирует с рабочими действиями.

Тексты

  • Каждый раздел говорит, для чего он нужен.
  • Ошибки объясняют причину и следующий шаг.
  • Слова "черновик", "скрыт", "нет в наличии" используются одинаково везде.

Визуальная иерархия

  • Главное действие выделено одним акцентом.
  • Опасные действия отделены цветом и подтверждением.
  • Списки плотные, но фото, цена и статус читаются без напряжения.
