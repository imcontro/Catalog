# Technical Spec: Cart, Checkout And WhatsApp v0.1

## 1. Назначение

Этот документ описывает техническую работу корзины, оформления заказа, доставки и WhatsApp-сообщения.

Он опирается на feature specs:

- `02-cart.feature-spec.md`;
- `03-checkout-and-whatsapp.feature-spec.md`;
- `04-delivery.feature-spec.md`.

## 2. Общая идея

Корзина хранится на стороне клиента.

На сервере заказ в первой версии не создается.

Перед отправкой в WhatsApp корзина должна сверяться с актуальными данными каталога.

В WhatsApp-сообщение попадают только доступные позиции.

## 3. Хранение корзины

Корзину можно хранить в `localStorage`.

Ключ:

```text
napitki_berkat_cart
```

Черновой формат позиции:

```text
CartItem
- productId
- flavorId
- quantity
- addedAt
- snapshotName
- snapshotFlavorName
- snapshotPriceRub
```

`snapshot` нужен только для временного отображения, пока актуальные данные не обновились.

Главным источником истины остаются актуальные данные с сервера.

## 4. Идентичность позиции

Позиция корзины определяется парой:

```text
productId + flavorId
```

Если у товара нет выбора вкуса, `flavorId` пустой.

Один товар с разными вкусами - разные позиции корзины.

Повторное добавление того же товара с тем же вкусом увеличивает `quantity`.

## 5. Количество

Количество хранится как целое число.

Минимум: `1`.

Плюс увеличивает количество на `1`.

Минус уменьшает количество на `1`.

Если количество становится меньше `1`, позиция удаляется.

Ручного ввода количества нет.

## 6. Актуализация корзины

При открытии страницы корзины `/cart`, открытии окна оформления заказа и перед отправкой заказа нужно получить актуальные данные по позициям:

```text
POST /api/cart/resolve
```

Запрос:

```text
items:
- productId
- flavorId
- quantity
```

Ответ должен вернуть:

- актуальное название товара;
- актуальное название вкуса;
- актуальную цену;
- актуальную ссылку на фото для корзины;
- доступность позиции;
- причину недоступности;
- признак скрытого или удаленного товара.

Фото для корзины выбирается так:

- если у выбранного вкуса есть отдельное фото, используется фото вкуса;
- если у выбранного вкуса нет отдельного фото, используется основное фото товара.

Если товар скрыт или удален, позиция удаляется из корзины.

Если товар или вкус стал **нет в наличии** после добавления в корзину, позиция остается видимой в корзине, но помечается как недоступная.

Клиент должен увидеть предупреждение, что недоступная позиция не попадет в WhatsApp-сообщение.

Если цена изменилась, цена обновляется и клиент видит предупреждение.

## 7. Суммы

Сумма позиции:

```text
effectivePriceRub * quantity
```

Общая сумма товаров считается только по доступным позициям.

Недоступные позиции:

- остаются видимыми в корзине;
- не участвуют в общей сумме;
- не участвуют в пороге бесплатной доставки;
- не попадают в WhatsApp-сообщение.

Доставка не входит в сумму товаров.

## 8. Подсказка по бесплатной доставке

Порог бесплатной доставки: `8000` рублей.

Подсказка показывается в корзине только если есть хотя бы одна доступная позиция.

Если сумма доступных позиций меньше `8000`, текст:

```text
До бесплатной доставки по г. Грозный осталось {остаток} руб.
```

Если сумма доступных позиций от `8000` включительно, текст:

```text
Доставка: бесплатно по г. Грозный
```

Остаток:

```text
8000 - сумма доступных позиций
```

## 9. Оформление заказа

Корзина открывается отдельной страницей:

```text
/cart
```

Отдельная страница оформления `/checkout` не используется.

Оформление заказа реализуется как почти полноэкранное окно поверх страницы `/cart`.

Окно оформления получает актуализированную корзину.

Кнопка **Оформить заказ** на странице `/cart` открывает окно оформления.

Если клиент закрывает окно оформления, он остается на странице `/cart`, а корзина сохраняется.

Перед отправкой нужно проверить:

- есть хотя бы одна позиция в корзине;
- есть хотя бы одна доступная позиция;
- адрес доставки заполнен;
- способ оплаты выбран.

Адрес доставки - обязательное текстовое поле.

Пример в поле адреса:

```text
Грозный ул. Назабраева 92
```

Способ оплаты:

- наличные;
- перевод.

## 10. Итоговая доставка

На оформлении заказа и в WhatsApp используется итоговая строка доставки.

Если сумма доступных позиций от `8000` включительно:

```text
Доставка: бесплатно по г. Грозный
```

Если сумма доступных позиций меньше `8000`:

```text
Доставка: стоимость сообщим в WhatsApp по тарифу
```

Сайт не проверяет город в адресе.

Сайт не рассчитывает точную стоимость доставки.

## 11. WhatsApp-сообщение

Сообщение формируется из доступных позиций.

Недоступные позиции не попадают в сообщение.

Первый текст:

```text
*Добрый день! Хочу сделать заказ!*
```

Строка товара с вкусом:

```text
Название товара вкус - 1уп
```

Строка товара без вкуса:

```text
Название товара - 1уп
```

Формат сообщения:

```text
*Добрый день! Хочу сделать заказ!*

*Товары:*
{строки товаров}

*Сумма товаров:* {sum} руб.
*Доставка:* {deliveryValue}
*Адрес:* {address}
*Оплата:* {paymentMethod}
```

В WhatsApp-сообщении не используются эмодзи, декоративные маркеры и нестандартные символы.

Постоянные подписи выделяются жирным через WhatsApp-разметку `*...*`.

`deliveryValue` берется из итоговой строки доставки без повторной подписи `Доставка:`.

Источник заказа в сообщение не добавляется.

Дата и время не добавляются.

Фраза подтверждения заказа не добавляется.

## 12. Открытие WhatsApp

Для отправки используется ссылка:

```text
https://wa.me/{phone}?text={encodedMessage}
```

`phone` хранится в настройках окружения.

Для первой версии используется номер владельца `89380046199`.

Для ссылки `wa.me` номер хранится в международном формате без плюса: `79380046199`.

`encodedMessage` должен быть URL-encoded.

Если WhatsApp не открылся, нужно показать официальное сообщение об ошибке.

После перехода по WhatsApp-ссылке корзина очищается.

Кнопка копирования текста заказа в первой версии не нужна.

## 13. Нестандартные ситуации

Нужно обработать:

- пустая корзина;
- в корзине только недоступные позиции;
- товар стал **нет в наличии**;
- вкус стал **нет в наличии**;
- товар скрыт;
- товар удален;
- цена изменилась;
- адрес не указан;
- способ оплаты не выбран;
- WhatsApp не открылся;
- сообщение стало слишком длинным.

## 14. Принятые решения

1. После перехода по WhatsApp-ссылке корзина очищается.
2. Если позиция стала недоступной после добавления в корзину, клиент видит предупреждение, что эта позиция не попадет в WhatsApp-сообщение.
3. Номер WhatsApp владельца: `89380046199`.
4. Для ссылки `wa.me` используется формат `79380046199`.
5. В WhatsApp-сообщении не используются эмодзи и декоративные маркеры.
6. Постоянные подписи WhatsApp-сообщения выделяются жирным через WhatsApp-разметку `*...*`.
