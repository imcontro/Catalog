# Дорожная Карта Работ

Эта папка хранит хронологическую историю выполненной разработки.

Она отличается от `docs/01-development-roadmap.md`:

- `docs/01-development-roadmap.md` - общий маршрут первой версии: куда проект должен прийти;
- `docs/roadmap/` - журнал фактически выполненных работ: что уже сделано, когда, по какому plan и в какой области проекта.

## Структура

- `timeline.md` - общий хронологический журнал выполненных работ;
- `areas/` - история по областям проекта.

## Когда обновлять

Дорожную карту нужно обновлять каждый раз, когда работа по конкретному work plan завершена и владелец после тестирования просит сделать push на GitHub.

Обновление дорожной карты выполняется перед commit/push/PR вместе с переносом work plan из `docs/work-plans/active/` в `docs/work-plans/completed/`.

## Что записывать

В `timeline.md` записывать:

- дату завершения;
- название work plan;
- ветку;
- Pull Request, если он уже известен;
- какие области проекта затронуты;
- кратко что сделано;
- какие проверки выполнены;
- важные заметки или ограничения.

В `areas/` обновлять только те области, которые реально затронуты выполненным plan.

## Правило

Дорожная карта не добавляет новые требования.

Она только сохраняет историю уже выполненной и проверенной работы.
