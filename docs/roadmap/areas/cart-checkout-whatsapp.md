# Cart, Checkout And WhatsApp

История работ по корзине, оформлению заказа и WhatsApp-сообщению.

## Записи

### 2026-06-14 - Страница корзины и окно оформления заказа

- Work plan: `docs/work-plans/completed/2026-06-14-cart-page-checkout-modal.work-plan.md`
- Ветка: `feature/cart-page-checkout-modal`
- Pull Request:

Сделано:

- Добавлена отдельная страница корзины `/cart`.
- Состав корзины показывается на странице с фото позиции, названием, вкусом, ценой, количеством и суммой.
- Фото позиции выбирается по вкусу, если у вкуса есть свое фото.
- Оформление заказа открывается как окно поверх страницы корзины.
- Старый маршрут `/checkout` удален.
- Перед отправкой в WhatsApp корзина повторно актуализируется через `POST /api/cart/resolve`.
- Скрытые и удаленные позиции удаляются из корзины, недоступные остаются видимыми и не попадают в WhatsApp.
- После открытия WhatsApp корзина очищается.

Проверено:

- `npm.cmd run lint`
- `npm.cmd run typecheck`
- `npm.cmd run build`
- `git diff --check`
- Владелец проверил локальный путь заказа и попросил сделать push.

### 2026-06-12 - Оформление заказа и WhatsApp

- Work plan: `docs/work-plans/completed/2026-06-12-checkout-whatsapp.work-plan.md`
- Ветка: `feature/checkout-whatsapp`
- Pull Request:

Сделано:

- Добавлена страница `/checkout` для оформления заказа.
- Добавлены обязательный адрес доставки и обязательный выбор оплаты.
- Оформление заказа актуализирует корзину через `POST /api/cart/resolve`.
- Недоступные позиции не попадают в WhatsApp и не участвуют в сумме товаров.
- Добавлено формирование WhatsApp-сообщения с приветствием, товарами, суммой, доставкой, адресом и оплатой.
- После открытия WhatsApp корзина очищается.
- WhatsApp-сообщение формируется без эмодзи, чтобы избежать вопросительных знаков на устройствах.

Проверено:

- `npm.cmd run lint`
- `npm.cmd run typecheck`
- `npm.cmd run build`
- `git diff --check`
- Владелец проверил локальное оформление заказа и WhatsApp-сообщение.

### 2026-06-12 - Корзина клиента

- Work plan: `docs/work-plans/completed/2026-06-11-cart.work-plan.md`
- Ветка: `feature/cart`
- Pull Request:

Сделано:

- Добавлена клиентская корзина для товаров и вкусов из каталога.
- Корзина хранится в `localStorage` и сохраняется после обновления страницы.
- Повторное добавление той же позиции увеличивает количество уп.
- Количество меняется только кнопками плюс и минус.
- Корзина открывается отдельной компактной кнопкой, а не занимает постоянное место рядом с каталогом.
- На телефоне корзина открывается как нижняя панель.
- Добавлены удаление позиции, очистка всей корзины, сумма товаров и подсказка бесплатной доставки.
- Добавлена актуализация корзины через `POST /api/cart/resolve`.

Проверено:

- `npm.cmd run lint`
- `npm.cmd run typecheck`
- `npm.cmd run build`
- `git diff --check`
- Владелец проверил локальную корзину и попросил сделать push.
