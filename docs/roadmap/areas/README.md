# Области Проекта

Эта папка хранит историю выполненной работы по областям проекта.

Файл области обновляется только тогда, когда завершенный work plan реально затронул эту область.

Если появилась новая область проекта, можно создать новый файл в этой папке.

## Шаблон записи в области

```text
### YYYY-MM-DD - Название work plan

- Work plan: `docs/work-plans/completed/file-name.work-plan.md`
- Ветка: `branch-name`
- Pull Request: `PR link or empty`

Сделано:

- ...

Проверено:

- ...
```

## Текущие области

- `frontend.md` - клиентский интерфейс и общие frontend-части;
- `design.md` - визуальные решения, UI-состояния, внешний вид;
- `admin.md` - админка и управление каталогом;
- `catalog.md` - клиентский каталог, товары, категории, поиск, вкусы;
- `cart-checkout-whatsapp.md` - корзина, оформление заказа и WhatsApp;
- `data-supabase.md` - база данных, Supabase, Storage, импорт данных;
- `deployment.md` - Vercel, окружения, деплой, эксплуатация;
- `docs-process.md` - документация, specs, work plans, правила процесса.
