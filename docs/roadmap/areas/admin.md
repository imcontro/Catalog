### 2026-06-27 - Админка: быстрая отметка товара нет в наличии

- Work plan: `docs/work-plans/completed/2026-06-27-admin-product-stock-quick-action.work-plan.md`

### 2026-06-27 - Админка: управление вкусами товара

- Work plan: `docs/work-plans/completed/2026-06-26-admin-product-flavors.work-plan.md`
- Ветка: `feature/admin-product-flavors`
- Pull Request:

Сделано:

- Форма товара теперь показывает существующие вкусы и состояние **Без выбора вкуса**.
- Владелец может включить или выключить выбор вкуса у товара.
- Владелец может добавить, изменить и удалить вкусы товара.
- Для вкуса можно сохранить отдельную цену, фото и отметку **Нет в наличии**.
- Сервер сохраняет вкусы вместе с товаром через защищенные API админки.
- Сервер не сохраняет включенный выбор вкуса без хотя бы одного вкуса.
- Сервер не сохраняет вкус без названия и проверяет корректность отдельной цены вкуса.
- Существующие `id` вкусов сохраняются при редактировании, чтобы корзина и клиентский каталог продолжали работать с выбранными вкусами.

Проверено:

- `npm.cmd run typecheck`
- `npm.cmd run lint`
- `npm.cmd run build`
- `git diff --check`
- Ручная проверка владельцем.

Заметки:

- Отдельная сортировка вкусов перетаскиванием и очистка старых фото не добавлялись.
