# Work Plan: формат WhatsApp-сообщения без эмодзи с жирными подписями

## 1. Статус

Утвержден владельцем для реализации.

## 2. Цель

Обновить шаблон WhatsApp-сообщения заказа так, чтобы постоянные строки были заметнее через жирные подписи WhatsApp-разметки, но без эмодзи и декоративных маркеров.

## 3. Источники требований

- `docs/features/03-checkout-and-whatsapp.feature-spec.md`;
- `docs/technical/03-cart-checkout-whatsapp.technical-spec.md`;
- `docs/user-stories/01-client-order-flow.user-stories.md`.

## 4. Scope

В рамках плана:

- обновить функцию формирования WhatsApp-сообщения в `CheckoutModal`;
- убрать эмодзи и декоративные маркеры из постоянных строк сообщения;
- выделить жирным только постоянные подписи:
  - приветствие;
  - `Товары:`;
  - `Сумма товаров:`;
  - `Доставка:`;
  - `Адрес:`;
  - `Оплата:`;
- оставить строки товаров компактными без жирного шрифта;
- оставить значения заказа обычным текстом;
- сохранить URL-кодирование сообщения через `encodeURIComponent`;
- убрать повторную подпись `Доставка:` из значения доставки в WhatsApp-сообщении.

## 5. Не входит в scope

- изменение полей оформления заказа;
- добавление имени клиента, телефона, комментария или даты;
- изменение правил доставки;
- изменение номера WhatsApp;
- сохранение заказа в базе данных;
- предпросмотр или копирование текста WhatsApp-сообщения;
- изменение админки, Supabase, миграций или API.

## 6. Новый формат сообщения

```text
*Добрый день! Хочу сделать заказ!*

*Товары:*
Мохито 0.45л клубника - 1уп
Кока-Кола ж/б 0.33л - 2уп

*Сумма товаров:* 3500 руб.
*Доставка:* стоимость сообщим в WhatsApp по тарифу
*Адрес:* Грозный ул. Назабраева 92
*Оплата:* наличные
```

## 7. План реализации

1. Создать отдельную ветку от актуального `main`.
2. Обновить сборку WhatsApp-сообщения в `src/components/checkout/CheckoutModal.tsx`.
3. Добавить небольшой helper для значения доставки без подписи `Доставка:`.
4. Проверить, что WhatsApp-ссылка по-прежнему собирается через `encodeURIComponent`.
5. Запустить `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd run build` и `git diff --check`.

## 8. Критерии готовности

- WhatsApp-сообщение начинается с `*Добрый день! Хочу сделать заказ!*`.
- Блок товаров начинается с `*Товары:*`.
- Строки товаров не меняют формат `Название товара вкус - 1уп`.
- Сумма, доставка, адрес и оплата имеют жирные подписи без эмодзи.
- Значение доставки не дублирует слово `Доставка:`.
- В WhatsApp попадают только доступные позиции.
- Бизнес-логика корзины, доставки и отправки заказа не меняется.
