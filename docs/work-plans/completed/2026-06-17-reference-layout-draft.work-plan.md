# Work Plan: черновая страница дизайна по принципам референса 39gudermes

## 1. Статус

Утвержден владельцем для черновой реализации.

Запрос владельца от 2026-06-17:

- текущий дизайн владельца не устраивает;
- нужно создать отдельную черновую страницу, а не менять основной каталог;
- визуально ориентироваться на принципы страницы `39gudermes.ru/category/...`;
- не копировать цвета, бренд, тексты и требования чужого сайта;
- не отходить от specs проекта.

Уточнение владельца от 2026-06-18:

- черновик должен быть сделан максимально близко к референсу по качеству и каркасу;
- допустимо повторить структуру почти один в один;
- исключения: не копировать цвета, бренд и не нарушать основные правила проекта.

## 2. Источники требований

- `docs/00-global-spec.md`;
- `docs/design/00-design-spec.md`;
- `docs/features/01-client-catalog.feature-spec.md`;
- `docs/features/02-cart.feature-spec.md`;
- `docs/features/03-checkout-and-whatsapp.feature-spec.md`;
- `docs/features/04-delivery.feature-spec.md`;
- референс `39gudermes.ru/category/d2b25c5e-05f7-4a97-8833-29f286604ba5` только как источник принципов размеров и компоновки.

## 3. Scope

Сделать отдельную черновую страницу:

- маршрут: `/design-draft/reference-layout`;
- страница не добавляется в клиентскую навигацию;
- страница не отправляет реальные заказы в WhatsApp;
- страница не меняет данные Supabase;
- страница нужна только для визуального утверждения владельцем.

Черновая страница должна сначала выглядеть как цельная рабочая страница каталога, а не как презентационная доска.

На этой же черновой странице можно ниже показать состояния ключевых экранов:

- каталог;
- корзина;
- окно оформления заказа.

## 4. Принципы, взятые с референса

Берем только размеры и принципы:

- центральный контейнер с максимальной шириной около `560px`;
- внешний padding страницы около `24px` на desktop и `16px` на mobile;
- шапка в три зоны: левая иконка `44px`, центр с логотипом, правая иконка `44px`;
- отдельный центрированный заголовок текущего раздела;
- 2-колоночная сетка карточек на mobile;
- gap сетки около `10-12px`;
- карточка с padding около `12-14px`;
- фото товара в квадратном блоке с `object-fit: contain`;
- цена заметнее названия;
- основная кнопка карточки высотой около `48px`;
- нижняя плавающая кнопка корзины после добавления товаров;
- корзина с карточками позиций и нижним итоговым блоком;
- оформление заказа как почти полноэкранное окно или bottom sheet.

Не берем:

- чужие цвета;
- чужой логотип;
- чужие тексты;
- чужую бизнес-логику;
- отсутствие поиска и фильтра **Все напитки**, потому что они обязательны в specs проекта.

## 5. План реализации

1. Создать route `/design-draft/reference-layout`.
2. Сверстать single-page черновик, где первый экран максимально повторяет каркас референса.
3. Использовать логотип NapitkiBerkat и палитру проекта.
4. Использовать mock-товары и локальные старые фото только для визуального черновика.
5. Добавить read-only route для показа локальных фото из `data/source-old-catalog/photos`.
6. Проверить `typecheck`, `lint` и сборку.

## 6. Критерии готовности

- Черновая страница открывается по `/design-draft/reference-layout`.
- Основной каталог `/` не меняется в рамках этого плана.
- Черновик визуально показывает размеры и принципы референса.
- На странице видны обязательные элементы specs: логотип, **Все напитки**, поиск, карточки с фото, ценой, `шт в уп`, вкусом, кнопкой корзины, корзина и оформление.
- Нет реальной отправки заказа в WhatsApp.
- Нет записи в Supabase.
