# Work Plan: Подготовка приложения

## Статус

Завершен. Владелец проверил результат и попросил сделать push на GitHub.

## Ветка

`feature/application-foundation`

## Основание

- тогдашний этап разработки: "Этап 1. Подготовка приложения";
- `docs/00-global-spec.md`;
- `docs/technical/00-technical-overview.technical-spec.md`;
- `docs/design/00-design-spec.md`.

## Цель

Создать техническую основу проекта, чтобы приложение запускалось локально и имело базовые страницы клиентского каталога и входа в админку без реальной бизнес-логики.

## Scope

В рамках этого плана делаем:

- создать Next.js / React / TypeScript приложение;
- настроить базовую структуру папок;
- добавить базовую главную страницу клиентского каталога;
- добавить страницу входа в админку без реальной логики авторизации;
- подготовить пример файла переменных окружения;
- убедиться, что приложение запускается локально;
- убедиться, что в репозитории нет реальных секретных ключей.

## Не делаем

- не подключаем Supabase;
- не создаем базу данных и миграции;
- не загружаем реальные товары и фото;
- не реализуем корзину;
- не реализуем отправку в WhatsApp;
- не реализуем реальную авторизацию админки;
- не реализуем полную админку управления каталогом;
- не настраиваем Vercel.

## Шаги реализации

1. Проверить текущее состояние репозитория и ветки.
2. Создать структуру Next.js-приложения с TypeScript.
3. Настроить базовые страницы `/` и `/admin/login`.
4. Добавить базовые стили с учетом design spec и русского интерфейса.
5. Добавить `.env.example` без реальных секретов.
6. Запустить проверки и локальный запуск.

## Проверка

- `npm run lint`;
- `npm run build`;
- локальный запуск приложения;
- открывается клиентская главная страница `/`;
- открывается заготовка страницы входа `/admin/login`;
- `git diff --check`;
- проверка, что реальные секреты не добавлены.
