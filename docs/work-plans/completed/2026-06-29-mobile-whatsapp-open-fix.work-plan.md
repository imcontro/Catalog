# Work Plan: исправление открытия WhatsApp на телефоне

## 1. Цель

Исправить отправку заказа в WhatsApp на телефоне, когда после нажатия **Отправить в WhatsApp** браузер показывает ошибку открытия приложения.

## 2. Основание

- `docs/features/03-checkout-and-whatsapp.feature-spec.md` требует, чтобы после нажатия **Отправить в WhatsApp** открывался WhatsApp с заранее сформированным сообщением.
- `docs/technical/03-cart-checkout-whatsapp.technical-spec.md` требует формат ссылки `https://wa.me/{phone}?text={encodedMessage}` и очистку корзины после перехода по WhatsApp-ссылке.

## 3. Причина

Текущая реализация открывает ссылку через `window.open(whatsAppUrl, "_blank")` после асинхронной проверки корзины.

На мобильных браузерах такой вызов может блокироваться как popup, потому что открытие происходит не сразу в момент пользовательского нажатия.

## 4. Scope

В рамках этого плана:

- оставить текущий формат WhatsApp-ссылки `wa.me`;
- заменить способ открытия ссылки на переход текущей вкладки через `window.location.href`;
- сохранить повторную актуализацию корзины перед отправкой;
- сохранить очистку корзины после подготовки перехода;
- убрать ложную ошибку, которая появлялась при заблокированном popup.

## 5. Не входит в scope

- изменение формата WhatsApp-сообщения;
- изменение номера WhatsApp;
- сохранение заказов в базе;
- добавление альтернативного канала отправки;
- изменение клиентского каталога, корзины и админки вне отправки WhatsApp.

## 6. Проверки

- `npm.cmd run lint`;
- `npm.cmd run typecheck`;
- `npm.cmd run build`;
- `git diff --check`;
- ручная проверка владельцем на телефоне после деплоя.

## 7. Выполнено

- В оформлении заказа сохранена повторная актуализация корзины перед отправкой.
- Формат WhatsApp-ссылки `https://wa.me/{phone}?text={encodedMessage}` не изменен.
- Открытие WhatsApp переведено с `window.open(..., "_blank")` на переход текущей вкладки через `window.location.href`.
- Корзина очищается перед переходом по WhatsApp-ссылке, как и раньше.
- Ложная ошибка о заблокированном popup больше не показывается при успешной подготовке ссылки.

## 8. Проверено

- `npm.cmd run lint`;
- `npm.cmd run typecheck`;
- `npm.cmd run build`;
- `git diff --check`.

## 9. Заметки

- Номер WhatsApp, формат сообщения, доставка, актуализация корзины и серверные API не менялись.
- Финальную проверку открытия WhatsApp нужно выполнить на телефоне после деплоя.
