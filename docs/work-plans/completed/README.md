# Completed Work Plans

Здесь хранится история завершенных планов разработки.

План переносится сюда из `active/` только после того, как:

- разработка по плану завершена;
- владелец протестировал результат;
- владелец попросил сделать push на GitHub;
- перед commit/push/PR нужно сохранить план как завершенный.
