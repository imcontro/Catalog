# Work Plan: перенос утвержденного reference layout в основной клиентский интерфейс

## 1. Статус

Утвержден владельцем для реализации.

Владелец 2026-06-18 утвердил черновой дизайн на `/design-draft/reference-layout` и разрешил переносить его на оригинальный клиентский интерфейс.

## 2. Источники требований

- `docs/00-global-spec.md`;
- `docs/design/00-design-spec.md`;
- `docs/features/01-client-catalog.feature-spec.md`;
- `docs/features/02-cart.feature-spec.md`;
- `docs/features/03-checkout-and-whatsapp.feature-spec.md`;
- `docs/features/04-delivery.feature-spec.md`;
- утвержденная черновая страница `/design-draft/reference-layout`.

## 3. Scope

Перенести утвержденный визуальный стиль на основную клиентскую часть:

- каталог `/`;
- корзина `/cart`;
- окно оформления заказа на странице корзины.

Не входит в scope:

- админка;
- изменение бизнес-логики;
- изменение формата WhatsApp-сообщения;
- изменение Supabase, данных, миграций или API;
- отправка тестовых реальных заказов в WhatsApp.

## 4. Утвержденные визуальные решения для переноса

- общий теплый светлый фон;
- центральный клиентский контейнер до `560px`;
- шапка с логотипом по центру и компактной корзиной справа;
- без кнопки назад в каталоге;
- под логотипом текст `NapitkiBerkat`;
- минималистичный поиск с аккуратной лупой;
- горизонтальный ряд категорий с легким намеком на скролл;
- карточки товаров в 2 колонки, с белой поверхностью, мягкой тенью, квадратным фото, заметной ценой и кнопкой;
- выбранный вкус показывается в названии после `/` приглушенным цветом;
- нижняя кнопка перехода в корзину глубокого графитового цвета;
- корзина с полным составом, количеством товаров/упаковок, итоговой суммой и действиями;
- окно оформления легче: без тяжелой темной подложки, с мягкими полями и заметной, но не сложной строкой доставки;
- кнопка WhatsApp в оформлении с иконкой WhatsApp и цветом, близким к WhatsApp.

## 5. План реализации

1. Перенести визуальный каркас каталога из draft в `CatalogClient`.
2. Перенести стили карточек товаров, поиска, категорий и нижней корзины в основной CSS.
3. Перенести стили корзины `/cart` и итогового блока.
4. Обновить окно оформления заказа и кнопку WhatsApp.
5. Проверить `typecheck`, `lint`, `build`.
6. Проверить локально маршруты `/` и `/cart`.

## 6. Критерии готовности

- Основной каталог визуально соответствует утвержденному draft-дизайну.
- Корзина и оформление заказа соответствуют утвержденному draft-дизайну.
- Поведение остается по specs: поиск, категории, выбор вкуса, корзина, оформление и WhatsApp не меняют бизнес-логику.
- Админка не изменена.
- Проверки проходят.
