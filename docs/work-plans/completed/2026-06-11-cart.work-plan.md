# Work Plan: Корзина клиента

Дата: 2026-06-11

Статус: completed

Рабочая ветка после утверждения плана: `feature/cart`

## 1. Цель

Сделать корзину клиента для уже работающего клиентского каталога.

Главный результат этого плана:

```text
Клиент добавляет доступные товары из каталога в корзину, меняет количество упаковок, видит состав заказа, сумму товаров и подсказку по бесплатной доставке.
```

Этот план закрывает этап roadmap **"Корзина"** без оформления заказа и без отправки в WhatsApp.

## 3. Scope работ

### 3.1. Добавление из каталога

Нужно:

- добавить действие **В корзину** для доступного товара;
- не давать добавить товар или вкус со статусом **нет в наличии**;
- для товара с выбором вкуса добавлять выбранный вкус;
- повторное добавление того же товара с тем же вкусом должно увеличивать количество уп;
- разные вкусы одного товара должны становиться разными позициями корзины;
- после добавления позиции на карточке товара вместо кнопки **В корзину** показывать плюс, количество уп и минус;
- изменение количества на карточке товара не должно автоматически открывать корзину.

### 3.2. Хранение корзины

Нужно:

- хранить корзину на клиенте в `localStorage`;
- использовать ключ `napitki_berkat_cart`;
- хранить `productId`, `flavorId`, `quantity`, `addedAt`, `snapshotName`, `snapshotFlavorName`, `snapshotPriceRub`;
- сохранять корзину между обновлениями страницы;
- не сохранять заказ на сервере.

### 3.3. Интерфейс корзины

Нужно:

- показать клиенту выбранные позиции корзины;
- не показывать корзину постоянно рядом с каталогом;
- показывать нормальную компактную кнопку корзины с краю экрана, когда есть выбранные позиции;
- на кнопке корзины показывать иконку корзины, текст **Корзина** и счетчик выбранных уп;
- по нажатию на кнопку корзины открывать отдельное окно корзины;
- если корзина стала полностью пустой, автоматически закрывать открытое окно корзины;
- на телефоне открывать корзину как нижнюю панель с крупными кнопками управления;
- показать выбранный вкус, если он есть;
- показать цену одной уп, количество уп, сумму позиции и общую сумму товаров;
- менять количество только кнопками плюс и минус;
- удалить позицию при минусе на `1 уп`;
- дать отдельную миниатюрную кнопку удаления позиции с иконкой урны;
- дать отдельную кнопку очистки всей корзины;
- показать пустое состояние, если товары не выбраны;
- не добавлять оформление заказа до отдельного следующего work plan.

### 3.4. Актуализация позиций

Нужно:

- добавить серверный `POST /api/cart/resolve`;
- сверять позиции корзины с актуальными данными Supabase;
- удалять из корзины скрытые и удаленные товары;
- оставлять видимыми позиции, которые стали **нет в наличии**, но не учитывать их в сумме;
- обновлять цену, если она изменилась;
- показывать официальное предупреждение для недоступных позиций и измененных цен.

### 3.5. Подсказка по доставке

Нужно:

- считать сумму только по доступным позициям;
- показывать подсказку, если есть хотя бы одна доступная позиция;
- если сумма меньше `8000` рублей, показывать текст `До бесплатной доставки по г. Грозный осталось {остаток} руб.`;
- если сумма от `8000` рублей включительно, показывать текст `Доставка: бесплатно по г. Грозный`.

## 4. Что не входит в этот план

В этот work plan не входит:

- страница или блок оформления заказа;
- кнопка или переход к оформлению заказа;
- обязательный адрес доставки;
- выбор способа оплаты;
- формирование WhatsApp-сообщения;
- открытие WhatsApp;
- очистка корзины после WhatsApp;
- админка;
- изменение схемы базы данных;
- деплой на Vercel.

## 5. Проверки

После реализации нужно проверить:

```text
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
git diff --check
git status --short --branch
```

Дополнительно вручную проверить локально:

- товар без вкусов добавляется в корзину;
- товар с выбранным вкусом добавляется отдельной позицией;
- повторное добавление той же позиции увеличивает количество;
- после добавления товара карточка показывает плюс, количество уп и минус вместо кнопки добавления;
- добавление и изменение количества на карточке не открывает корзину автоматически;
- компактная кнопка корзины с иконкой, текстом и счетчиком появляется с краю экрана;
- окно корзины открывается только после нажатия на кнопку корзины;
- если последняя позиция удалена, окно корзины закрывается автоматически;
- на телефоне окно корзины открывается как удобная нижняя панель;
- плюс и минус меняют количество уп;
- минус на `1 уп` удаляет позицию;
- отдельное удаление позиции работает через миниатюрную кнопку с иконкой урны;
- очистка корзины работает;
- корзина сохраняется после обновления страницы;
- сумма и подсказка бесплатной доставки обновляются при изменении количества;
- недоступный товар или вкус нельзя добавить;
- пустая корзина показывает понятное состояние.

## 6. Критерии готовности

План считается выполненным, когда:

- клиент может собрать корзину из товаров каталога;
- корзина хранится между обновлениями страницы;
- позиции корзины отображаются с количеством `уп`, ценой и суммой;
- общая сумма считается только по доступным позициям;
- подсказка по бесплатной доставке работает по specs;
- недоступные позиции не участвуют в сумме;
- скрытые и удаленные позиции удаляются из корзины при актуализации;
- интерфейс и сообщения на русском языке;
- проверки завершились успешно;
- результат показан владельцу для ручной проверки.
