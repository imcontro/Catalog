# Work Plans

Эта папка хранит конкретные планы разработки.

Роудмап отвечает на вопрос: **в каком общем порядке развивается проект**.

Work plan отвечает на вопрос: **что именно делаем в одной конкретной ветке разработки**.

Дорожная карта `docs/roadmap/` отвечает на вопрос: **что уже было сделано и в каких областях проекта**.

## Структура

- `active/` - планы, по которым работа еще идет;
- `completed/` - планы, по которым работа завершена, отправлена в GitHub и оформлена через Pull Request.

## Жизненный цикл плана

1. Владелец просит составить конкретный plan.
2. AI-агент создает файл плана в `docs/work-plans/active/`.
3. После утверждения плана создается отдельная Git-ветка.
4. Разработка идет по этому плану.
5. Когда владелец протестировал результат и попросил сделать push на GitHub, файл плана переносится из `active/` в `completed/`.
6. После переноса плана обновляется дорожная карта в `docs/roadmap/`.
7. После обновления дорожной карты выполняются commit, push и Pull Request.
8. Владелец сам делает merge Pull Request на GitHub.

## Название файлов

Рекомендуемый формат:

```text
YYYY-MM-DD-short-plan-name.work-plan.md
```

Пример:

```text
2026-06-04-project-setup.work-plan.md
```
