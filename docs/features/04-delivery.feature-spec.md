# Feature Spec: Delivery v0.1

## 1. Назначение

Этот spec описывает правила отображения доставки в первой версии проекта.

Доставка в первой версии не рассчитывается автоматически. Сайт показывает клиенту подсказку до бесплатной доставки в корзине и итоговую информацию по доставке перед отправкой заказа в WhatsApp.

## 2. Пользователь

Основной пользователь: клиент магазина.

Клиент видит подсказку по бесплатной доставке в корзине.

Клиент видит итоговую информацию по доставке на оформлении заказа.

## 3. Главное правило доставки

Итоговая строка доставки зависит от суммы доступных позиций, которые реально отправляются в заказ.

Порог 8000 рублей считается только по доступным позициям.

Недоступные позиции, скрытые позиции, доставка, скидки и другие возможные начисления в этот порог не входят.

Для подсказки в корзине используется тот же порог и та же сумма доступных позиций.

## 4. Адрес доставки

Адрес доставки обязателен для отправки заказа.

Адрес нужен работнику магазина, чтобы обработать заказ и уточнить доставку при необходимости.

Сайт не проверяет, находится ли адрес в городе Грозный.

Адрес доставки не используется сайтом для автоматического расчета доставки.

## 5. Отображение доставки

Доставка отображается в двух режимах: подсказка в корзине и итоговая строка на оформлении заказа и в WhatsApp-сообщении.

В корзине:

- если корзина пустая или в корзине нет доступных позиций, подсказка по бесплатной доставке не показывается;
- если сумма доступных позиций меньше 8000 рублей, клиент видит текст "До бесплатной доставки по г. Грозный осталось {остаток} руб.";
- если сумма доступных позиций от 8000 рублей включительно, клиент видит текст "Доставка: бесплатно по г. Грозный".

Остаток считается как 8000 рублей минус сумма доступных позиций.

На оформлении заказа и в WhatsApp-сообщении:

- если сумма доступных позиций от 8000 рублей включительно, клиент видит текст "Доставка: бесплатно по г. Грозный";
- если сумма доступных позиций меньше 8000 рублей, клиент видит текст "Доставка: стоимость сообщим в WhatsApp по тарифу".

Если сумма доступных позиций меньше 8000 рублей, сайт не должен показывать точную итоговую сумму с доставкой.

## 6. Основной сценарий

1. Клиент выбирает товары.
2. Сайт считает сумму доступных позиций.
3. Клиент видит в корзине подсказку по бесплатной доставке.
4. Клиент открывает оформление заказа.
5. Клиент указывает адрес доставки.
6. Сайт показывает итоговую строку доставки по правилу суммы.
7. Информация по доставке попадает в WhatsApp-сообщение.

## 7. Нестандартные ситуации

Нужно предусмотреть:

- клиент не указал адрес доставки;
- сумма доступных позиций ровно 8000 рублей;
- сумма доступных позиций изменилась после изменения количества;
- клиент уменьшил заказ ниже 8000 рублей;
- клиент увеличил заказ до 8000 рублей или больше.
