# Feature Spec: Checkout And WhatsApp v0.1

## 1. Назначение

Этот spec описывает оформление заказа и отправку заказа в WhatsApp.

Оформление заказа нужно, чтобы клиент указал обязательные данные, выбрал способ оплаты и отправил работнику магазина понятное сообщение.

## 2. Пользователь

Основной пользователь: клиент магазина.

Получатель результата: работник магазина, который получает заказ в WhatsApp.

## 3. Что клиент должен сделать

Перед отправкой заказа клиент должен:

- проверить выбранные товары;
- увидеть сумму товаров;
- указать адрес доставки;
- увидеть информацию по доставке;
- выбрать способ оплаты;
- нажать "Отправить в WhatsApp".

## 4. Обязательные данные

Для отправки заказа обязательно:

- в корзине должен быть хотя бы один товар;
- в корзине должна быть хотя бы одна доступная позиция;
- адрес доставки должен быть указан;
- способ оплаты должен быть выбран.

Имя клиента указывать не нужно.

Телефон клиента отдельно указывать не нужно, потому что заказ отправляется через WhatsApp.

## 5. Способ оплаты

В первой версии доступны два способа оплаты:

- наличные;
- перевод.

Клиент должен выбрать один способ оплаты перед отправкой заказа.

Онлайн-оплата на сайте не входит в первую версию.

## 6. Информация по доставке

Перед отправкой заказа клиент должен видеть информацию по доставке.

Правила доставки описаны отдельно в spec `04-delivery`.

Подсказка по бесплатной доставке в корзине описана отдельно в spec `04-delivery`.

На оформлении заказа показывается итоговая информация по доставке.

Точный текст итоговой информации по доставке берется из spec `04-delivery`.

## 7. WhatsApp-сообщение

После нажатия "Отправить в WhatsApp" должно сформироваться аккуратное сообщение.

Сообщение должно быть понятно работнику магазина без дополнительной расшифровки.

Минимальное содержание сообщения:

- приветствие: "Добрый день! Хочу сделать заказ!";
- компактный список товаров;
- выбранный вкус товара в строке товара, если у товара есть вкусы;
- количество уп по каждому товару;
- сумма товаров;
- информация по доставке;
- адрес доставки;
- способ оплаты.

Строка товара должна быть короткой:

```text
Название товара вкус - 1уп
```

Если у товара нет выбора вкуса, строка должна быть:

```text
Название товара - 1уп
```

Если объем, тара или формат важны для клиента, они должны быть частью названия товара. Отдельно расписывать объем в WhatsApp-сообщении не нужно.

В WhatsApp-сообщение попадают только доступные позиции.

Недоступные позиции, которые остались видимыми в корзине, не попадают в WhatsApp-сообщение.

Сумма товаров в WhatsApp-сообщении считается только по доступным позициям, которые реально отправляются в заказ.

В списке товаров не нужно отдельно расписывать "Количество", "Цена" и "Сумма" для каждой позиции.

## 8. Пример структуры сообщения

```text
Добрый день! Хочу сделать заказ!

Товары:
Мохито 0.45л клубника - 1уп
Кока-Кола ж/б 0.33л - 2уп

Сумма товаров: 3500 руб.
Доставка: стоимость сообщим в WhatsApp по тарифу
Адрес доставки: ...
Оплата: наличные
```

Пример сообщения при сумме доступных позиций от 8000 рублей:

```text
Добрый день! Хочу сделать заказ!

Товары:
Мохито 0.45л клубника - 4уп
Кока-Кола ж/б 0.33л - 5уп

Сумма товаров: 8200 руб.
Доставка: бесплатно по г. Грозный
Адрес доставки: ...
Оплата: перевод
```

## 9. Проверки перед отправкой

Если корзина пустая, заказ нельзя отправить.

Если в корзине нет доступных позиций, заказ нельзя отправить.

Если в корзине есть доступные и недоступные позиции, заказ можно отправить только с доступными позициями.

Если адрес доставки не указан, заказ нельзя отправить.

Поле адреса должно показывать пример формата адреса: "Грозный ул. Назабраева 92".

Если способ оплаты не выбран, заказ нельзя отправить.

Клиент должен понять, что именно нужно исправить.

## 10. Основной сценарий

1. Клиент собрал корзину.
2. Клиент открывает оформление заказа.
3. Клиент вводит адрес доставки.
4. Клиент выбирает способ оплаты.
5. Клиент проверяет сумму товаров и информацию по доставке.
6. Клиент нажимает "Отправить в WhatsApp".
7. Открывается WhatsApp с заранее сформированным сообщением.
8. Клиент отправляет сообщение работнику магазина.

## 11. Нестандартные ситуации

Нужно предусмотреть:

- пустая корзина;
- в корзине есть только недоступные позиции;
- не указан адрес доставки;
- не выбран способ оплаты;
- WhatsApp не открылся;
- сообщение получилось слишком длинным из-за большого заказа.

Если WhatsApp не открылся, нужно показать официальное сообщение об ошибке.

## 12. Правила первой версии

- Заказ отправляется только в WhatsApp.
- На сайте не нужна онлайн-оплата.
- Имя клиента не спрашиваем.
- Адрес доставки обязателен.
- В поле адреса должен быть пример: "Грозный ул. Назабраева 92".
- Способ оплаты обязателен.
- Сообщение должно начинаться с фразы "Добрый день! Хочу сделать заказ!".
- Позиции товаров в WhatsApp-сообщении должны быть компактными.
- Объем, тара или формат товара указываются в названии товара, если они важны для клиента.
- Отдельно расписывать объем товара в WhatsApp-сообщении не нужно.
- В WhatsApp-сообщение попадают только доступные позиции.
- Сумма товаров считается только по доступным позициям.
- Фразу "Пожалуйста, подтвердите заказ" добавлять не нужно.
- Дату и время формирования заказа добавлять не нужно.
- Предпросмотр WhatsApp-сообщения перед открытием WhatsApp не нужен.
- Кнопка копирования текста заказа при ошибке открытия WhatsApp не нужна.
- Работник должен получить понятный список товаров, выбранные вкусы, количество уп и сумму.
