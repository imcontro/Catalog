# Feature Spec: Checkout And WhatsApp v0.1

## 1. Назначение

Этот spec описывает оформление заказа и отправку заказа в WhatsApp.

Оформление заказа нужно, чтобы клиент указал обязательные данные, выбрал способ оплаты и отправил работнику магазина понятное сообщение.

## 2. Пользователь

Основной пользователь: клиент магазина.

Получатель результата: работник магазина, который получает заказ в WhatsApp.

## 3. Что клиент должен сделать

Перед отправкой заказа клиент должен:

- проверить выбранные товары;
- увидеть сумму товаров;
- указать адрес доставки;
- увидеть информацию по доставке;
- выбрать способ оплаты;
- нажать "Отправить в WhatsApp".

## 4. Обязательные данные

Для отправки заказа обязательно:

- в корзине должен быть хотя бы один товар;
- адрес доставки должен быть указан;
- способ оплаты должен быть выбран.

Имя клиента указывать не нужно.

Телефон клиента отдельно указывать не нужно, потому что заказ отправляется через WhatsApp.

## 5. Способ оплаты

В первой версии доступны два способа оплаты:

- наличные;
- перевод.

Клиент должен выбрать один способ оплаты перед отправкой заказа.

Онлайн-оплата на сайте не входит в первую версию.

## 6. Информация по доставке

Перед отправкой заказа клиент должен видеть информацию по доставке.

Правила доставки описаны отдельно в spec `04-delivery`.

Если сумма товаров от 8000 рублей, в заказе должна быть понятная информация, что доставка бесплатная.

Если сумма товаров меньше 8000 рублей, в заказе должна быть понятная информация, что стоимость доставки сообщат в WhatsApp по тарифу.

## 7. WhatsApp-сообщение

После нажатия "Отправить в WhatsApp" должно сформироваться аккуратное сообщение.

Сообщение должно быть понятно работнику магазина без дополнительной расшифровки.

Минимальное содержание сообщения:

- заголовок заказа;
- список товаров;
- количество упаковок по каждому товару;
- цена по каждой позиции;
- сумма по каждой позиции;
- сумма товаров;
- информация по доставке;
- адрес доставки;
- способ оплаты;
- текст, что заказ пришел из каталога NapitkiBerkat.

## 8. Пример структуры сообщения

```text
Заказ из каталога NapitkiBerkat

Товары:
1. Название товара
   Количество: 2 упаковки
   Цена: 1000 руб.
   Сумма: 2000 руб.

2. Название товара
   Количество: 1 упаковка
   Цена: 1500 руб.
   Сумма: 1500 руб.

Сумма товаров: 3500 руб.
Доставка: стоимость сообщим в WhatsApp по тарифу
Адрес доставки: ...
Оплата: наличные
```

Текст примера можно менять позже, но смысл и состав данных должны сохраниться.

## 9. Проверки перед отправкой

Если корзина пустая, заказ нельзя отправить.

Если адрес доставки не указан, заказ нельзя отправить.

Если способ оплаты не выбран, заказ нельзя отправить.

Клиент должен понять, что именно нужно исправить.

## 10. Основной сценарий

1. Клиент собрал корзину.
2. Клиент открывает оформление заказа.
3. Клиент вводит адрес доставки.
4. Клиент выбирает способ оплаты.
5. Клиент проверяет сумму товаров и информацию по доставке.
6. Клиент нажимает "Отправить в WhatsApp".
7. Открывается WhatsApp с заранее сформированным сообщением.
8. Клиент отправляет сообщение работнику магазина.

## 11. Нестандартные ситуации

Нужно предусмотреть:

- пустая корзина;
- не указан адрес доставки;
- не выбран способ оплаты;
- WhatsApp не открылся;
- сообщение получилось слишком длинным из-за большого заказа.

## 12. Правила первой версии

- Заказ отправляется только в WhatsApp.
- На сайте не нужна онлайн-оплата.
- Имя клиента не спрашиваем.
- Адрес доставки обязателен.
- Способ оплаты обязателен.
- Работник должен получить понятный список товаров и сумму.

## 13. Вопросы для проверки владельцем

1. Нужно ли добавлять в сообщение фразу "Пожалуйста, подтвердите заказ"?
2. Нужно ли добавлять дату и время формирования заказа?
3. Нужно ли показывать клиенту предпросмотр WhatsApp-сообщения перед открытием WhatsApp?
